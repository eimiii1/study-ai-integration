# Study AI Integration

Backend service for an AI-powered study platform. Built with Flask, it handles authentication, data management, and AI-powered quiz generation through the Groq API.

## Documentation

- [Setup Guide](docs/setup.md) — getting the backend and frontend running
- [API Reference](docs/api-reference.md) — full list of endpoints
- [Testing Guide](docs/testing.md) — how to test the API with cURL or Postman
- [Features Overview](docs/features.md) — decks, subdecks, flashcards, notes, quizzes, and furniture rewards

## Tech Stack

- **Backend:** Flask, Flask-SQLAlchemy, Flask-JWT-Extended, Flask-CORS
- **Database:** MySQL
- **Frontend:** React (Vite)
- **AI:** Groq API
